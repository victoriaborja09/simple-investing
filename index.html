Prototype notes

This is designed as an app-style case study prototype, not a live brokerage product. The flow focuses on simplicity and confidence for first-time investors.

  • Default contribution set to $50/month
  • Portfolio uses 56% SPYM, 14% VXUS, 30% SGOV
  • Includes a language switcher for translated UI
  • Includes a long-term investing page with an interactive graph
